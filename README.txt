IMPORTANT: The original Sophia ZIP was not accessible in this environment, so the
media files themselves are NOT included. HTML keeps the correct relative asset
paths. Extract the seven media files directly into this folder's assets/ directory.

HOW TO PREVIEW WITHOUT GITHUB
1. Open the project folder in VS Code or GitHub Codespaces.
2. Add the media to assets/.
3. Preview index.html using Live Server or the editor's preview feature.
4. Test index.html, services.html, about.html, events.html at a narrow phone
   viewport (e.g. 375 px) and at desktop width (e.g. 1280 px).
5. Verify nav, links, audio playback after adding files, and required form
   validation. The HTML demo interest form does not send to a server.
6. When ready, commit/push to your own GitHub repo yourself; no GitHub action
   has been performed for you.
7. Add your public repository URL to the submission document before uploading.
